# Проекты, реализованные в Яндекс.Практикуме на курсе «Анализ данных»

Сборка учебных проектов по анализу данных и машинному обучению. Каждый проект оформлен в виде Jupyter Notebook и сопровождается кратким описанием в README соответствующей папки.

## Структура репозитория

| Папка | Содержание |
| :---- | :--------- |
| [`E-commerce/`](E-commerce/) | Анализ товарного ассортимента интернет-магазина |
| [`ML/`](ML/) | Прогнозирование оттока клиентов сети фитнес-центров |

## Список проектов

| Название | Задача | Стек |
| :------- | :----- | ---: |
| [E-commerce — Анализ товарного ассортимента](E-commerce/E-commerce.ipynb) | Интернет-магазину товаров для дома требуется полноценный анализ товарного ассортимента. Необходимо выделить основной и дополнительный ассортимент, а также сформулировать рекомендации по повышению эффективности работы магазина. | `pandas`, `numpy`, `matplotlib`, `seaborn`, `scipy` |
| [Прогноз оттока посетителей из сети фитнес-центров](ML/Анализ%20оттока%20клиентов%20фитнес-клуба.ipynb) | Построение модели прогнозирования факта оттока посетителей сети фитнес-центров и сегментация (кластеризация) клиентов. | `pandas`, `scipy`, `matplotlib`, `seaborn`, `sklearn` |

## Технологии

- **Язык:** Python
- **Анализ данных:** pandas, NumPy, SciPy
- **Визуализация:** Matplotlib, Seaborn
- **Машинное обучение:** scikit-learn
- **Формат:** Jupyter Notebook

## Как запустить проекты

```bash
git clone https://github.com/dobrachev/praktikum.git
cd praktikum
pip install pandas numpy scipy matplotlib seaborn scikit-learn jupyter
jupyter notebook
```

После запуска откройте нужную папку и выберите `.ipynb`-файл проекта.
